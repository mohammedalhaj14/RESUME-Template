## ⚙️ How to Customize and Deploy

### 1. **Customization**

1.  **Fork** this repository.
2.  Edit the content directly within the **`index.html`** file, replacing the placeholder text with your personal information, experience, and skills.
3.  (Optional) Adjust the primary color palette in the **`style.css`** file.

### 2. **Deployment**

You can easily host and share your personalized resume online for free:

* **Option A: GitHub Pages**
    * Go to **Settings** > **Pages** in your forked repository.
    * Select the `main` branch and the `/ (root)` folder.
    * Your live resume will be available at `https://<your-username>.github.io/RESUME-Template/`.
* **Option B: Local File**
    * Open the `index.html` file in your browser to view and print/save as a PDF.
